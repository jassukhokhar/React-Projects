# Employee Management System

A responsive Employee Management System (EMS) built with React and Tailwind CSS that enables admins to assign tasks, monitor progress, and manage employees through dedicated dashboards.

## Tech Stack

* React
* Tailwind CSS
* Context API
* Local Storage
* JavaScript

## Features

* Admin and Employee authentication
* Role-based dashboards
* Task creation and assignment
* Task status management
* Context API state management
* Local storage persistence
* Responsive user interface

## Run

```bash
npm install
npm run dev
```
